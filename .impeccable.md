## Design Context

### Users
- Hackathon judges evaluating an autonomous trading agent demo
- Crypto traders / developers who want to see the agent's live reasoning
- Primary context: desktop viewing during a demo video / live demo
- Job to be done: Understand what the agent is doing, why, and how well it's performing

### Brand Personality
- **Voice**: Raw, mechanical, utilitarian — a military-grade terminal that happens to be beautiful
- **Tone**: Cold precision with warmth from the amber phosphor glow. Not sterile — alive.
- **3 Words**: Technical, refined, unexpected
- **Emotional goals**: Confidence (this thing works), focus (the data is all that matters), and understated delight (the terminal glow is beautiful but never decorative)

### Aesthetic Direction
- **Visual tone**: Industrial CRT terminal aesthetic — late 1970s/early 1980s mainframe terminal reinterpreted with modern precision
- **Theme**: Dark background with phosphor amber text, subtle green accents, terminal glow effects
- **References**: Bloomberg terminal + old VT100 + modern dataviz dashboard
- **Anti-references**: Generic SaaS dashboard, glassmorphism cards, rounded corners, side-stripe borders

### Design Principles
1. **Every pixel is data** — no decorative elements, every visual choice serves information
2. **Terminal borders are sacred** — square corners, thin 1px borders, phosphor glow on hover
3. **Amber is the soul** — the amber color palette is the primary identity, not an accent
4. **Motion is signal** — animations only for data changes (price ticks, status transitions), not decoration
5. **Monospace is the truth** — all data in monospace, proportional only for long-form text
